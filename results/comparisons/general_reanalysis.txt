General model, ABP from PPG, MAP: generation against the regression twin, and within- and between-patient behaviour.
Same 7,200 test segments. Intervals are 95% from a bootstrap over the 144 test patients (1,000 resamples).
"constant bar" is one Gaussian error bar of fixed width around a point prediction, fitted on half of the test
patients and scored on the other half. m3 (Table 3, with calibration) is listed because its file carries the
calibration readings the script needs. The script reads the saved draws (*.npz) and the patient codes, which are
not in this repository; for this run the files were placed in one folder under the names shown.

$ python scripts/reanalyze.py --results <folder> --arms g1_twin g1 g1_seed1 g1_abpw g1_abpw_seed1 s_ppg g1_ft_ppg m1_seed0 m1_seed1 m3 \
      --cal-from m3 --pulse-only g1_twin --data results/ids
